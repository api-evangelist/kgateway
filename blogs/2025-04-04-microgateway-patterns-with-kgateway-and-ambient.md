Microgateway Patterns with kgateway and Ambient Legacy API gateways like Apigee and cloud provider API gateways have long been used to manage API traffic, especially for ingress. They run in a stand-alone model and provide “big front door” style perimeter security capabilities. They were designed for monolith workloads running on virtual machines (VMs).
